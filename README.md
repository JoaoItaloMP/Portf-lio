# 💻 João Italo | Developer Portfolio

Portfólio profissional desenvolvido com foco em apresentar meus projetos, habilidades e evolução como desenvolvedor front-end/mobile.

O projeto foi construído utilizando HTML, CSS e JavaScript puro, com uma interface moderna inspirada em landing pages premium, animações suaves e identidade visual focada em tons de azul neon/dark.

# 📌 Sobre o Projeto

Este portfólio foi desenvolvido com o objetivo de:

- apresentar meus projetos pessoais e acadêmicos
- demonstrar minhas habilidades em desenvolvimento web
- praticar conceitos modernos de UI/UX
- consolidar conhecimentos em front-end
- construir uma presença profissional online

O projeto possui uma interface responsiva e moderna, inspirada em layouts premium utilizados por desenvolvedores e startups atuais.
